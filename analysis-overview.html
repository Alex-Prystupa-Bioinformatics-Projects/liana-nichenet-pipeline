LRP Pipeline — Analysis Overview

Three analyses are run in sequence by scripts/main.R. Each is described below: what it does, its assumptions, the thresholds applied, and what the output plots show.

1. LIANA Only

Script: scripts/run-liana.R

What it does

Runs all built-in LIANA scoring methods (natmi, connectome, logfc, scsr, etc.) via liana_wrap(), then aggregates them into a single aggregate_rank per LR pair per sender→receiver combination using liana_aggregate(). Every expressed LR pair across all sender→receiver combinations is scored.

Assumptions

  • No filtering at run time — all pairs are saved regardless of significance.
  • Aggregate rank is a rank-aggregation across methods, not a p-value. Lower = more consistently ranked significant.
  • Does not model downstream target gene activity — purely interaction-level scoring.
  • Sender and receiver identities come from Final_Annotations in the Seurat object metadata.

Thresholds

None applied during this step. All pairs are written to CSV. Downstream filtering (e.g. aggregate_rank < 0.05) happens in the combined analysis.

Outputs

FileContents
liana/results/liana-lr-full-results.csvAll LR pairs, all sender→receiver combinations
liana/results/liana-lr-{sender}_{receiver}-results.csvFiltered to one sender→receiver pair
liana/plots/{sender}_{receiver}.pdfBarplot — see below

Plots

Barplot (one PDF per sender→receiver pair): shows top LR pairs ranked by aggregate score. The lower the aggregate rank, the more methods agree the interaction is significant.

2. NicheNet Only

Script: scripts/run-nichenet.R — standard mode (nichenet.mode: standard in config.yml)

What it does

For each niche, identifies differentially expressed genes in the receiver cell type, then scores sender-expressed ligands by how well their known downstream target network (from the NicheNet prior) explains those DE genes. The score is a Pearson correlation between the ligand's predicted target weights and the observed DE gene set. Top ligands are then matched to expressed receptors in the receiver for visualization.

DE genes are computed once globally between the two receiver cell types (FindMarkers(), Seurat), then each niche uses the genes upregulated in its own receiver as the gene set of interest.

Assumptions

  • Target prediction is ligand-only. The ligand_target_matrix is indexed by ligand — receptor identity has no effect on predicted target genes. Two LR pairs sharing the same ligand will produce identical target lists.
  • DE genes are defined relative to the other receiver (Squamous vs. Columnar), not against a global background.
  • Circos shows only the highest-expressing sender per ligand (not all senders) to avoid clutter.
  • Potential ligands must be expressed in at least one sender AND have a cognate receptor expressed in the receiver.

3. LIANA + NicheNet Combined

Script: scripts/run-liana-nn-combined.R

What it does

Takes precomputed LIANA results and filters to statistically significant pairs, then re-scores the surviving ligands using NicheNet with receiver-specific DE genes. This produces a set of interactions that are significant by both expression-based scoring (LIANA) and target-gene-activity scoring (NicheNet). Runs per sender within each niche.

Assumptions

  • Requires LIANA results and NicheNet DE genes to be saved from the previous two steps.
  • Each sender is analyzed independently — results are not pooled across senders at the scoring stage.
  • NicheNet target prediction remains ligand-only (same limitation as above).
  • GO enrichment is only run for ligands with pearson > 0 (negative values indicate no predictive signal).
  • Ligands must appear in both the LIANA filtered set AND the ligand_target_matrix to be scored.

Thresholds

ParameterValueApplied to
aggregate_rank_threshold<0.05Hard LIANA significance ceiling
top_n_liana_interactions50Max LIANA pairs kept per sender→receiver (after rank filter)
top_n_nn_ligands25Top NicheNet ligands shown (by pearson)
top_n_targets250Predicted target genes per ligand
pearson > 0—Ligand must have positive activity for GO enrichment

Plots

Barplot (left panel, per sender): x = NicheNet Pearson score, y = ligand (ordered by Pearson ascending). Shows the ligand activity strength — how well the ligand's target network explains receiver DE genes.

Heatmap (right panel, per sender): x = receptor, y = ligand (same order as barplot), fill = LIANA aggregate_rank. Red = low rank = more significant; white = less significant. Lets you see which receptor each ligand pairs with and how confidently LIANA scores those pairs.

Circos (per niche, all senders combined, 12×10 in): same layout as the NicheNet-only circos, but edge weight is 1 − aggregate_rank (LIANA-derived). Only pairs passing aggregate_rank < 0.05 are included. Top 3 receptors per ligand shown. Legend on page 2.
